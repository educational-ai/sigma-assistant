С помощью numpy.linalg.eig получаем:

Собственные значения: $\lambda_1 = 3$, $\lambda_2 = 1$

Собственные векторы (нормированные):

Для $\lambda_1 = 3$: $\mathbf{v}_1 = (0.707,\; 0.707)^T$ (это $\frac{1}{\sqrt{2}}(1,1)^T$)

Верификация $A\mathbf{v} = \lambda \mathbf{v}$ для обоих векторов подтверждает результат (вывод Python: Совпадают: True).
